规则

计分

21 分一局，每球得分；20 平后净胜 2 分；25 平后一球定胜负（最高 26 分）。

限时

预计 13 分钟一局，按现场实际情况调整；不设时间上限，打到分出胜负。

间隔

场间休息约 1 分钟，按现场实际情况开下一轮。

名次

决赛胜者冠军、负者亚军；3、4 名比赛的胜者第三、负者第四。

让分

混双里的男双遇到混双，混双 6:0 开局；男双让 6 分。

为什么会有轮空？

单败淘汰的签位必须是 4、8、16 这种 2 的倍数。三个项目都铺不满：男双 6 对进 8 位签表，第 1 轮只打 2 场，剩下 2 对轮空；女双 5 对进 8 位，第 1 轮只打 1 场，剩下 3 对轮空；混双 11 对进 16 位，第 1 轮打 3 场，剩下 5 对轮空。轮空数 = 签位数 − 对数，所以一共 10 对轮空，全部集中在第 1 轮，第 2 轮起每一列都是满的。轮空位由抽签决定，设置里也可以改成按等级给种子。

常见问题

轮空的人会少打吗？

会少打一场，而且只少第 1 轮：轮空的一对直接进下一轮，之后每轮照常出场。所以男双、女双的冠军打 2 场（有轮空）或 3 场，混双冠军打 3 场（有轮空）或 4 场。轮空等于少一场消耗，是抽签带来的优势，不会少拿名次。

轮空算赢吗？不记比分怎么算？

算直接晋级，不用上场，也不填比分；对阵图里用虚线框写在“轮空”，下一轮的格子里就是这一对。

混双里的男双让几分？

默认让 6 分，混双从 6:0 开始；在“设置”里可以改。

比分填让分前还是让分后？

填最终比分。比如混双从让分后的比分开始，最后打到 21:15，就填 21 和 15。

打到多少分算赢？20 平、25 平怎么算？

21 分一局；20 平后要净胜 2 分；打到 25 平，谁先再得 1 分谁赢，最高 26 分。所以 25:24 还没打完，26:24 或 26:25 才算；弃权记 21:0。

比分没填到终局会怎样？

页面上没打完或多打的比分（比如 25:24、27:25）会标红并提示还没结束，不会判胜晋级；改成终局比分后才生效。

同一个人能打男双和混双吗？

可以。男双和混双是两个项目；赛程已经把男双、女双分开，混双放在最后。

输了还能打吗？

正常输了就结束（3、4 名比赛除外，那是给决赛前一轮负者打的）。唯一的例外：有人临时缺席、指定候补又不够用时，可以从这个项目里已经输掉、人还在场的人里抽签顶上——抽签决定，不能自己挑，而且只顶缺阵球员那个项目。

换手机或电脑怎么看？

线上版用同一个口令登录就能看（发布过的赛果会自动拉下来）。本机只在当前浏览器里记登录状态和自己的编辑，换设备重新输一次口令即可；管理端的“导出 / 导入”JSON 是备份和搬家用的。

现场流程从签到到颁奖
  1. 签到点名：对着名单点人，缺席的当场定性（候补顶上 / 去掉 / 弃权），把结论记下来。候补优先用指定候补；指定候补用掉后，从该项目已输掉、人还在场的人里抽签，抽中的只顶该项目。
  2. 抽签并公示：点「抽签」，抽完自动上锁（防止现场误点重抽）。把种子数字记下来，出问题时能原样重抽回来。签表举手机给全场看一圈。
  3. 宣读规则：照「规则口径」里的口播稿念一遍，只念一次，别零散解释。
  4. 开赛：按时间线 T1 开始叫号，两片场同时开打。
  5. 每场循环：叫号 → 在对阵图那张卡片上点「上场」（排到空着的 5 / 6 号场，同时记下开打时间，卡片亮绿框并显示已打时长；两片场各点一次，就是两场同时打）→ 打球 → 报分 → 记分员确认 → 总裁判录比分（录成终局比分时结束时间自动记成这一刻；不是终局的比分——没打完或多打——页面会标红、不判胜）→ 再叫下一场。录完终局比分才放下一场，否则队伍会散。
  6. 提前或落后都不用改计划时间：每场实际开始/结束时间一记，后面的时段自动跟着走 —— 超时显示「顺延 → 新时间」，打得快显示「提前 → 新时间」，两个方向都会跟着走；想强制改开始时间，去设置里改「开始时间」。
  7. 更新赛程：在「对阵图」卡片里填终局比分，页面自动更新胜者和进度；没打完或多打的比分会标红、不判胜，改到终局才生效。时间线这页也会跟着刷新。
  8. 阶段发布：每打完 2–3 个时段点一次「发布」，观看端约 1 分钟内自动刷新，不用挨个私聊。
  9. 中场休息：男双 / 女双打完、混双开打前休息 分钟，混双换人、补水、擦汗都在这会儿。
  10. 收官：3、4 名赛 → 决赛 → 冠军名单生成 → 颁奖。
  11. 收尾：走下面的「收尾清单」，别漏归还场地这一条。

每场循环里最容易出错的是比分录错：填的是最终比分（让分之后的比分）；没打完或多打的比分（25:24、27:25）会标红、不判胜。改比分直接在卡片上改，改完下游会自动清空，把下游重录一遍即可。

规则口径全场统一版本

下面这些数字跟「设置」里的一致（改了设置，这里跟着变）。有争议时以这一栏为准。

    开场口播稿照着念就行

    口播稿只念规则，不解释为什么让分、为什么轮空——有疑问的人比赛后再问，场上不讨论。

    预案出问题照着做

    每条都写了三件事：怎么办（人怎么做）和页面上的操作（点哪里）。顺序就是处置顺序。

    • 场地被别人占了 / 只剩一片场先找场馆换场或换时段；换不了就串行——先打完男双女双，再打混双，结束时间整体顺延，休息照旧不压缩。页面：设置 → 时间与让分 → 改「开始时间」，赛程时间自动重算；比赛顺序不变。
    • 下雨 / 灯光不足 / 场地在室外当天早上就定，别拖到开赛。改室内或整体顺延，然后群里统一通知一次，别口头各说各话。页面：设置 → 赛事 → 改「开始时间」。
    • 有人临时缺席先问一句「能不能来」；来不了就候补顶上，顶不上就把他从名单里去掉。人少不凑错，宁可少打一场。页面：设置 → 候补替换：优先用「指定候补」；指定候补用掉后，从「输掉的人」里抽（选项目 → 取消勾选已提前走的人 → 抽签 → 用抽中的人替换，只顶该项目）。改完记得重新公示。
    • 缺席太多，对数不够某个项目凑不满就直接砍掉这个项目；落单的人并进别的队要当场宣布并记下来。改完名单必须重抽对阵。页面：设置 → 签表锁 → 解锁 → 点「抽签」重抽（会换掉全部对阵，重抽完必须重新公示给全场）。
    • 有人迟到还没开赛的项目可以等 10 分钟；已经叫号没到，判该场弃权（对方 ），当场宣布。页面：不用动，直接在群里说明。
    • 有人受伤先停赛、照顾伤者：这场按弃权处理；后面还打不了就按「有人临时缺席」换候补（指定候补 / 从该项目已淘汰、还在场的人里抽签，只顶该项目）；要整场作废再解锁重抽对阵（搭档不变）。页面：设置 → 候补替换 或 设置 → 签表锁 → 解锁 → 只重抽对阵。
    • 比分填错了 / 没打完 / 多打不是终局的比分（25:24、27:25 这种）页面会标红、不判胜，把数字改成终局比分即可；改完下游场次会自动清空，把下游那几场重录一遍。页面：对阵图 → 那场的两个比分框 → 改完按回车。
    • 想重抽签重抽会让全场记住的签表作废，重抽完必须重新公示一次；同种子 + 同名单 = 同一个结果，所以先把原种子记下来。页面：设置 → 签表锁 → 解锁 → 「抽签」（全部重抽）或「只重抽对阵」（搭档不变）；种子填回原数字可原样重现。
    • 误进演示模式演示数据带水印，绝对不要发布。页面：顶部横幅「退出演示」/「一键复原锁定签表」。
    • 发布失败 / 没网看报错：409 是远端刚被改过，等 30 秒再点一次；Token 被拒就去 GitHub 重发一个 token；实在发不出去就用手机拍下对阵图照片 + 群里口头通知，别让全场干等。页面：工具栏「发布」；备用：本地 publish.sh。
    • 手机没电 / 页面崩了签表存在这台设备的浏览器里，换设备用导出的 JSON 恢复。页面：工具栏「导出」存 JSON → 新设备「导入」。
    • 比分有争议比分牌 → 双方自报 → 判不了由总裁判拍板，当场定完不再改；赛后申诉只做记录，不改结果。页面：不用动。
    • 观众挡场 / 拍照 / 围观两片场之间留出通道；只在两场之间的休息时间拍照；要比分就让记分员播报，不要围观解说。页面：不用动。
    • 打不完 / 时间拖长不压缩休息、不缩短局数；实在不够就砍掉 3、4 名赛（当场宣布，冠军不受影响）。页面：每场的实际结束时间记上以后，后面的时段会自动顺延显示，不用手改计划时间；想强制改开始时间才去设置 → 时间与让分。
    • 奖品不够 / 发错奖品按「3 个项目 × 5 档」核对，发之前念一遍名次和奖品；不够的用小挂件补。页面：不用动。
    • 网名不一致 / 有人要求改名以报名网名为准，签表上的名字就是最终名字；要改统一在赛后改，不要在场上临时改。页面：对阵图上的队名可以直接改，改完自动保存。
    • 抽签后误点又重抽了真实抽签后会自动上锁；万一重抽了，把原种子填回种子框再抽一次就是原来那版。页面：种子输入框 → 填回原数字 → 抽签。
